# NASA Space Apps Seoul 2026 홍보 페이지

의존성 없는 정적 페이지입니다. `index.html`을 열면 로컬에서 확인할 수 있고, GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다.

챌린지 14개를 분야별로 탐색할 수 있으며, 참가 절차·일정·FAQ·공식 커뮤니티를 안내합니다. JavaScript가 꺼져도 전체 챌린지와 본문을 읽을 수 있습니다. 스크롤 등장 효과는 사용자의 동작 줄이기 설정을 따릅니다. 첫 화면의 홍보 포스터를 누르면 원본을 새 탭에서 볼 수 있습니다.

## 정보와 이미지 출처

- 행사 날짜, 참가 방식, 등록 절차: [NASA Space Apps Seoul 2026 공식 사이트](https://nasaspaceappskr.org/2026/ko/)
- 챌린지 및 NASA 등록 링크: [NASA Space Apps Challenge](https://www.spaceappschallenge.org/2026/)
- 홍보 포스터: 운영진 제공 PNG 원본, 비율과 내용 변경 없이 사용
- Space Apps 로고: 서울 공식 사이트의 `images/logo/logo.svg`, 비율과 색상 변경 없이 사용

행사 정보와 14개 챌린지 요약은 2026-09-29 공식 사이트에서 확인했습니다. 이후 일정·프로그램 변경은 각 공식 링크에서 확인해주세요.
